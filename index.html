Gerador de Link NFC

Gere o link de avaliação do Google para o cartão NFC e veja os locais que a equipe já visitou.

A lista compartilhada ainda não foi ligada a esta página. O gerador de link funciona normalmente, mas nada é cadastrado para a equipe.

Entrar

Revendedor:

1. Confira se o local já foi cadastrado

    2. Descubra o Place ID do local

    1. Abra a ferramenta de Place ID do Google.
    2. No mapa da página, digite o nome do local no campo Enter a location e escolha o resultado certo (confira o endereço).
    3. Aparece uma janelinha com o Place ID, um código que começa com ChIJ. Copie esse código.

    3. Gere o link e cadastre

    Testar link

    Antes de gravar no cartão, use Testar link e confirme que abre a tela de avaliação do local certo.
